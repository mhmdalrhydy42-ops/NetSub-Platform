# NetSub Platform

## Project Idea
NetSub Platform is a modern web platform for managing internet subscription packages, service providers, subscription requests, payment status, and subscription tracking.

The project is inspired by a database system for an internet subscription platform. It allows users to view internet packages, choose a service provider, submit a subscription form, and monitor subscription status through an interactive dashboard.

## Project Purpose
This project was developed as a final project for the Web Technology course.  
It focuses on building a professional and interactive frontend interface using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome Icons
- Google Fonts

## Main Features
- Modern responsive landing page
- Navigation bar with mobile menu
- Dark and light mode
- Arabic and English language support
- RTL layout support for Arabic
- Internet packages section
- Service providers section
- Provider packages modal
- Subscription form
- JavaScript form validation
- Interactive dashboard
- Dashboard table filters
- Add subscriptions from form to dashboard
- Save subscriptions using localStorage
- Delete subscription with confirmation
- Footer with project information
- Fully responsive design for mobile, tablet, and desktop
