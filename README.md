# NetSub Platform

## Project Idea
NetSub Platform is a web interface for managing internet subscription packages, service providers, users, and payment status.

The project is inspired by a database system for an internet subscription platform. It allows users to view internet packages, choose a service provider, submit a subscription form, and view subscription status in a simple dashboard.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
NetSub-Platform/
- index.html
- css/style.css
- js/main.js
- images/
- README.md

## Main Features
- Responsive navigation menu
- Modern landing page
- Internet package cards
- Service providers section
- Subscription form
- JavaScript form validation
- Dashboard table
- Dark and light mode
- Interactive buttons and filters
